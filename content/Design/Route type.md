### Route type

Route type adalah property tentang rute yang dilalui object dari satu point ke point lain

#### Direct

Direct berarti object itu hanya  memiliki 2 waypoint, yaitu origin (titik keberangkatan) dan destination (titik kedatangan)

#### Indirect

Indirect berarti object ini memiliki lebih dari 2 waypoint
Bisa jadi suatu object dengan indirect route type memiliki banyak waypoint

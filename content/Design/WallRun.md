Wall run adalah combination action
Wall run adalah unlockable action
Wall run berarti berlari dengan meniti wall
Wall run bisa digunakan untuk mengakses area yang "jalan satu-satunya" hanya berupa wall
Player bisa melakukan wall run dengan cara melakukan run searah paralel dengan wall tapi agak miring menghadap wall lalu jump dan ketika player character awal menyentuh wall, player menekan input dash

Wall run memiliki trajectory. Jadi seiring dengan waktu arah laju wall run akan menurun mengikuti gravitasi

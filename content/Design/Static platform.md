Static platform adalah platform yang:
Tidak [[Moveable]]

Platform ini bisa jadi akan ditaruh "melayang" pada game space

Terdapat variasi static platform dalam hal ukuran yang bisa diabstraksikan berdasarkan grid ukurannya:
Ukuran paling besar adalah 3x3 grid static platform
Ukuran paling kecil adalah 1x1 grid static platform

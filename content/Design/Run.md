Player bisa melakukan run
Run adalah action default yang dilakukan player character ketika bergerak

> [!info] Walk
> Tidak ada action walk dalam game ini. Jadi begitu player character bergerak, dia akan masuk ke action run

Run dalam game ini memiliki akselerasi. Jadi ketika mulai melakukan run, kecepatan run relatif kecil, tapi seiring dengan waktu maka kecepatannya akan bertambah.

Akselerasi saat berlari akan menambah daya  dorong ke depan saat melakukan [[Jump]]

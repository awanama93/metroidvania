Vertical wall run adalah unlockable wall run
Vertical wall run berarti melakukan wall run tapi secara vertikal
Vertical wall run bisa digunakan untuk mencapai area yang jauh lebih tinggi dari yang bisa diakses oleh [[DoubleJump]]
Player bisa melakukan vertical wall run dengan cara [[Run]] ke arah wall lalu jump dan ketika player character agak dekat dengan wall, player menekan input dash
